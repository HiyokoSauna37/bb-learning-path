How to use this site

  • Phase 0 から順番に進める。各 Phase は前の Phase の知識を前提にしている
  • 分からない用語は Module 00 の用語集に戻る。初出の英語用語は日本語注釈付き
  • Theory だけ読んで次に行かない。各モジュールの Practice / WSA Lab を必ず1つはやる
  • Phase 2 まで完了すれば huntr で最初のレポートを書ける。それが最初のマイルストーン
  • "Mark Complete" ボタンで進捗を記録。ブラウザに保存されるのでいつでも再開可能
