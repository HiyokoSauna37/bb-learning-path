Tax & Legal

BB を副業として継続するための税務・法務知識。 20万円ルール、W-8BEN、不正アクセス禁止法との境界。

Theory

日本の税務ルール

20万円ルール

  • 給与所得者で、給与以外の所得（BB bounty 等）が年間20万円以下なら確定申告不要
  • 「所得」= 収入 - 経費。経費を差し引いた後の金額で判定
  • 20万円を超えた場合は確定申告が必要
  • 注意: 20万円以下でも住民税の申告は必要（後述）
  • 年末調整の対象外（会社の年末調整ではカバーされない）

住民税: 普通徴収を選択

  • 確定申告時に住民税の徴収方法を「普通徴収（自分で納付）」にする
  • これにより副業収入分の住民税が会社の給与天引きに含まれない
  • = 会社に副業がバレにくい
  • 20万円以下で確定申告不要でも、市区町村に住民税の申告は別途必要

所得区分

  • BB 報酬は「雑所得」に分類（事業所得にするには開業届が必要）
  • 雑所得 = 収入金額 - 必要経費
  • 為替レート: 受取日の TTB レート（外貨建ての場合）
  • HackerOne は USD 建て → PayPal/銀行送金時のレートで計算

W-8BEN (米国源泉徴収)

概要

  • US platform (HackerOne, Bugcrowd) から bounty を受け取る場合に必要
  • W-8BEN = 「非居住外国人」の申告書。日米租税条約の適用を受けるため
  • 未提出の場合: 30% の源泉徴収が適用される
  • 提出済みの場合: 日米租税条約により 0% (royalties/services の場合)

手続き

  1. HackerOne / Bugcrowd の Tax Settings で W-8BEN フォームに記入
  2. マイナンバー (Individual TIN) を記入
  3. Treaty country: Japan, Article: 7 (Business Profits) or 22 (Other Income)
  4. 有効期限: 3年。期限切れ前に更新が必要

会社の副業規定

SoftBank 副業規定 (確認事項)

  • SoftBank は副業を原則許可している（事前届出制）
  • BB は「セキュリティリサーチ」として届出可能か確認
  • 競業避止: SOC 業務と直接競合しないことを確認
  • 時間管理: 本業に支障がないことが条件
  • 機密情報: 会社の業務情報を BB に利用しないこと

経費として計上可能なもの

BB 活動に直接必要な支出は経費として収入から差し引ける:

  • Burp Suite Pro ライセンス
  • VPS / クラウドサーバ代
  • ドメイン取得費
  • セキュリティ関連書籍
  • Training course / Certification
  • ハードウェア（テスト用デバイス）
  • インターネット回線費 (按分)
  • 電気代 (按分)
  • カンファレンス参加費
  • 交通費 (カンファレンス)

注意: 按分 = BB に使用した割合のみ。100% 計上は税務調査で否認される。領収書・利用記録を保管。

法的考慮事項

不正アクセス禁止法との境界

  • 日本法上、不正アクセス禁止法（平成11年法律第128号）は「正当な理由なく」アクセス制御を突破する行為を禁止
  • BB program の scope 内テストは「正当な理由あり」と解釈されうるが、判例が少ない
  • Scope 外のアセットへのテストは絶対に行わない
  • 日本企業の program は特に慎重に scope を確認

安全に活動するための原則

  • Scope 厳守: Program が明示的に許可したアセットのみテスト
  • Safe Harbor: Program の Safe Harbor 条項を確認。記載がない program は慎重に
  • 他ユーザへの実害なし: テストは自分のアカウント間でのみ。他者のデータに触れない
  • DoS 禁止: Rate limit テストやブルートフォースは明示的に許可されていない限り避ける
  • 記録保持: テスト内容のログを残す（万が一の場合に正当性を証明）
  • Responsible Disclosure: Program のルールに従う。勝手に公開しない

Responsible Disclosure のルール

  • Platform のルールに従う（disclosure timeline は program が決める）
  • Vendor に十分な修正期間を与える（通常 90日が業界標準）
  • 修正前に公開しない（0-day disclosure は法的リスクが高い）
  • Program が disclosure を許可した場合のみ公開する

記録管理

  • 収入記録: Platform 別の bounty 受取日、金額 (USD + JPY換算)、レート
  • 経費記録: 日付、金額、用途、領収書の保管
  • Submission log: 提出日、program、result、bounty 金額 (mei-bb の _submission_log.md)
  • 年間集計: 12月末に年間収支を確定。20万円超なら確定申告準備
  • 保管期間: 5年間（税務調査に備えて）
