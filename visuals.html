OAuth 2.0 Authorization Code Flow

正常フロー (上) と攻撃ポイント (赤) を重ねて表示。

sequenceDiagram participant U as User Browser participant C as Client App participant AS as Auth Server participant RS as Resource Server U->>C: 1. Login ボタンクリック C->>U: 2. Auth Server へリダイレクト Note right of C: redirect_uri 指定
攻撃: Open Redirect で
redirect_uri を書き換え U->>AS: 3. ログイン + 同意 AS->>U: 4. Authorization Code 付きリダイレクト Note right of AS: code=abc123
攻撃: Referer 漏洩
攻撃: CSRF で code 奪取 U->>C: 5. callback?code=abc123 C->>AS: 6. Code to Token 交換 Note right of C: client_secret 使用
攻撃: secret 漏洩チェック AS->>C: 7. Access Token 返却 C->>RS: 8. Token で API アクセス RS->>C: 9. ユーザーデータ
